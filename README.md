# BoatJump

보트 레이싱 맵을 위한 Paper 플러그인입니다. 서버에만 설치하면 되고, 접속하는 플레이어는 바닐라 클라이언트를 그대로 사용합니다.

> 아직 개발 중인 플러그인입니다. 동작과 명령어, 설정 항목은 바뀔 수 있습니다.

## 기능

- **턱 오르기**: 보트나 뗏목을 타고 가다가 앞에 한 칸 높이의 얼음 블록이 있으면, 순간이동 없이 자연스럽게 올라탑니다. 계단처럼 이어진 얼음은 내려앉지 않고 한 단씩 이어서 오르며, 오르는 동안에도 방향을 조종할 수 있습니다.
- **마커**: 막대기로 범위를 지정해 두면, 그 범위에 들어선 보트의 속도가 정해진 배수만큼 바뀝니다.
- **튕김**: 넘을 수 없는 벽에 부딪히면 뒤로 튕기고, 슬라임 블록을 밟으면 위로 튕깁니다. 마커 안의 바닥을 블록 종류와 관계없이 슬라임처럼 튕기게 하거나, 바닥에 떨어졌을 때 다시 튀어 오르게 할 수도 있습니다.
- **뛰어넘을 블록 지정**: 보트가 올라탈 블록의 종류를 명령어로 추가하거나 삭제할 수 있습니다. 처음에는 얼음 계열 4종이 들어 있습니다.

## 요구 사항

- Paper 26.3
- Java 25 이상

서버 내부 클래스를 사용하므로 Paper 26.3에 맞추어져 있습니다. 다른 버전에서는 동작하지 않을 수 있습니다.

## 설치

[Releases](../../releases)에서 jar 파일을 받아 서버의 `plugins` 폴더에 넣고 서버를 재시작합니다.

## 명령어

모든 명령어는 `boatjump.admin` 권한이 필요하며, 기본적으로 관리자(op)에게만 허용됩니다.

이름을 적지 않는 명령어는 **지금 서 있는 마커**를 대상으로 합니다. 마커 밖에 서 있으면 **바라보는 마커**를 대상으로 하고, 그런 마커도 없으면 기본값을 대상으로 합니다.

### 마커

| 명령어 | 설명 |
|---|---|
| `/보트점프 막대기` | 마커 막대기를 받습니다. 블록을 좌클릭하면 첫째 지점, 우클릭하면 둘째 지점이 지정됩니다. |
| `/보트점프 생성 <이름>` | 막대기로 선택한 범위로 마커를 만듭니다. |
| `/보트점프 삭제 <이름>` | 마커를 지웁니다. |
| `/보트점프 리스트` | 모든 마커의 이름과 그룹, 범위를 봅니다. |
| `/보트점프 정보` | 지금 서 있거나 바라보는 마커의 설정값을 봅니다. |
| `/보트점프 정보 <이름>` | 그 마커의 설정값을 봅니다. |
| `/보트점프 설정 <항목> <값>` | 지금 서 있거나 바라보는 마커의 설정값을 고칩니다. |
| `/보트점프 설정 <이름> <항목> <값>` | 그 마커의 설정값을 고칩니다. |

이름 자리에 `기본값`을 적으면 마커 밖에서 쓰이는 기본값을 보거나 고칩니다.

### 그룹

그룹에 넣은 마커들은 그룹의 설정값을 함께 씁니다. 그룹에 속한 마커는 자신의 설정값 대신 그룹의 설정값을 따르므로, 그런 마커를 따로 고치려면 먼저 그룹에서 빼야 합니다.

| 명령어 | 설명 |
|---|---|
| `/보트점프 생성 그룹 <이름>` | 빈 그룹을 만듭니다. |
| `/보트점프 삭제 그룹 <이름>` | 그룹을 지웁니다. 속해 있던 마커는 그룹의 설정값을 물려받고 남습니다. |
| `/보트점프 정보 그룹 <이름>` | 그 그룹의 설정값과 속한 마커를 봅니다. |
| `/보트점프 그룹 추가 <그룹>` | 지금 서 있거나 바라보는 마커를 그 그룹에 넣습니다. 없는 그룹이면 새로 만듭니다. |
| `/보트점프 그룹 제거 <그룹>` | 지금 서 있거나 바라보는 마커를 그 그룹에서 뺍니다. 마커는 그룹의 설정값을 물려받습니다. |
| `/보트점프 그룹 리스트` | 모든 그룹과 속한 마커를 봅니다. |
| `/보트점프 그룹 정보` | 지금 서 있거나 바라보는 마커가 속한 그룹의 설정값을 봅니다. |
| `/보트점프 그룹 설정 <항목> <값>` | 지금 서 있거나 바라보는 마커가 속한 그룹의 설정값을 고칩니다. |

`그룹 정보`와 `그룹 설정`은 항목 앞에 그룹 이름을 적어서, 그 자리에 서 있지 않아도 쓸 수 있습니다. (`/보트점프 그룹 설정 <그룹> <항목> <값>`)

### 점프블록

| 명령어 | 설명 |
|---|---|
| `/보트점프 점프블록 추가 <블록...>` | 보트가 한 칸 높이일 때 뛰어넘을 블록을 추가합니다. |
| `/보트점프 점프블록 삭제 <블록...>` | 보트가 뛰어넘을 블록을 목록에서 삭제합니다. |
| `/보트점프 점프블록 리스트` | 보트가 뛰어넘는 블록의 목록을 봅니다. |

블록 이름은 `blue_ice`처럼 영어 식별자로 적습니다.

### 입력을 돕는 기능

- 명령어를 입력할 때 자동 완성 목록의 항목에 마우스를 올리면 설명이 보입니다.
- `/보트점프`만 입력하면 도움말이 나오며, 각 줄에 마우스를 올리면 설명이 보이고 클릭하면 입력창에 채워집니다.
- 영어로도 입력할 수 있습니다. (`/boatjump set <이름> multiplier 2`, `wand`, `create`, `remove`, `list`, `info`, `set`, `group add|remove|list|info|set`, `jumpblock add|remove|list`)
- 막대기를 들고 있는 동안에는 범위가 선으로 표시됩니다. 선택 중인 범위는 흰색, 마커는 초록색, 설정값을 고친 마커는 파란색입니다. 이 선은 막대기를 든 플레이어에게만 보입니다.

## 설정 항목

속도 변화는 마커 안에서만 일어나고, 튕김 관련 항목은 마커 밖에서도 기본값으로 동작합니다.

| 한국어 | 영어 | 설명 | 초기값 |
|---|---|---|---|
| `사용` | `enabled` | 마커의 속도 변화를 켤지 여부. `켜기`(`true`) 또는 `끄기`(`false`) | 켜기 |
| `배율` | `multiplier` | 마커에 들어설 때 속도에 곱하는 배수. 1보다 작으면 느려집니다. | `2.0` |
| `추가속도` | `bonus` | 배수와 별도로 더하는 속도 (블록/틱) | `0` |
| `최고속도` | `max` | 속도 변화로 도달할 수 있는 최고 속도 (블록/틱) | `8.0` |
| `간격` | `interval` | 마커 안에서 다시 적용하는 간격 (틱). `0`이면 들어설 때 한 번만 적용합니다. | `0` |
| `벽튕김` | `wallbounce` | 넘을 수 없는 벽에 부딪혔을 때 뒤로 튕기는 정도. 부딪힌 속도에 곱합니다. | `0.5` |
| `탄성` | `elasticity` | 탄성 계수. 바닥에 떨어졌을 때 떨어진 속도에 곱해서 다시 튀어 오릅니다. | `0` |
| `슬라임` | `bounce` | 마커 안의 바닥을 슬라임처럼 만듭니다. 블록의 종류와 관계없이, 바닥에 닿으면 이 속도(블록/틱)로 위로 튕깁니다. | `0` |
| `슬라임블록` | `slime` | 실제 슬라임 블록을 밟았을 때 위로 튕기는 속도 (블록/틱). 마커 밖에서도 동작합니다. | `0.5` |

### 무작위 값

숫자 항목의 값 자리에 `무작위`(`random`)를 넣으면, 정해진 틱마다 값이 무작위로 바뀝니다.

```
무작위 [최소 최대] [틱]
```

| 입력 | 동작 |
|---|---|
| `무작위` | 항목별 기본 범위에서 4틱마다 바뀝니다. |
| `무작위 10` | 기본 범위에서 10틱마다 바뀝니다. |
| `무작위 0.5 3` | 0.5~3 사이에서 4틱마다 바뀝니다. |
| `무작위 0.5 3 20` | 0.5~3 사이에서 20틱마다 바뀝니다. |

## 빌드

속도 패킷을 직접 보내기 위해 Paper 서버의 내부 jar를 참조합니다. 이 파일은 저장소에 포함되어 있지 않으므로, 먼저 Paper 26.3 서버를 `server` 폴더에서 한 번 실행하여 `server/versions/26.3/paper-26.3.jar`가 생성되도록 해야 합니다.

```
./gradlew build
```

빌드에는 JDK 25 이상이 필요합니다. 결과물은 `build/libs`에 생성됩니다.
