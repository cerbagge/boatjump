# BoatJump

보트 레이싱 맵을 위한 Paper 플러그인입니다. 서버에만 설치하면 되고, 접속하는 플레이어는 바닐라 클라이언트를 그대로 사용합니다.

## 기능

- **턱 오르기**: 보트나 뗏목을 타고 가다가 앞에 얼음 턱이 있으면, 순간이동 없이 자연스럽게 올라탑니다. 계단처럼 이어진 얼음은 내려앉지 않고 한 단씩 이어서 오르며, 오르는 동안에도 방향을 조종할 수 있습니다. 한 번에 오를 수 있는 높이는 설정으로 정합니다.
- **마커**: 막대기로 범위를 지정해 두면, 그 범위마다 보트의 동작을 따로 정할 수 있습니다. 여러 마커를 그룹으로 묶어서 한 번에 고칠 수도 있습니다.
- **속도 변화**: 마커에 들어선 보트를 정해진 값만큼 빠르게 하거나 느리게 합니다.
- **탄성**: 높은 곳에서 떨어진 보트가 다시 튀어 오르고, 넘을 수 없는 벽에 부딪힌 보트가 뒤로 튕깁니다.
- **점프**: 마커 안의 바닥이나 슬라임 블록에 닿은 보트를 위로 띄웁니다.
- **무작위 값**: 설정값이 정해진 시간마다 무작위로 바뀌게 할 수 있습니다.
- **뛰어넘을 블록 지정**: 보트가 올라탈 블록의 종류를 명령어로 추가하거나 삭제할 수 있습니다. 처음에는 얼음 계열 4종(얼음, 꽁꽁 언 얼음, 푸른얼음, 살얼음)이 들어 있습니다.

모든 움직임은 순간이동이 아니라 보트의 속도를 바꾸는 방식으로 처리합니다. 그래서 화면이 끊기지 않고, 이동과 충돌은 게임의 원래 물리를 그대로 따릅니다.

## 요구 사항

- Paper 26.3
- Java 25 이상

서버 내부 클래스를 사용하므로 Paper 26.3에 맞추어져 있습니다. 다른 버전에서는 동작하지 않을 수 있습니다.

## 설치

1. [Releases](../../releases)에서 jar 파일을 받습니다.
2. 서버의 `plugins` 폴더에 넣습니다.
3. 서버를 재시작합니다.

설치만 해도 한 칸 높이의 얼음 턱을 오르는 기능은 곧바로 동작합니다. 나머지 기능은 아래의 명령어로 설정합니다.

## 빠른 시작

```
/보트점프 막대기                    막대기를 받습니다.
(블록을 좌클릭, 다른 블록을 우클릭)   범위를 지정합니다.
/보트점프 생성 가속                  그 범위로 "가속"이라는 마커를 만듭니다.
/보트점프 설정 가속 속도 20          그 마커에 들어선 보트를 초당 20블록 빠르게 합니다.
```

## 명령어

모든 명령어는 `boatjump.admin` 권한이 필요하며, 기본적으로 관리자(op)에게만 허용됩니다.

`설정`과 `그룹 설정`에는 대상의 이름을 반드시 적습니다. 이름을 적지 않아도 되는 명령어는 **지금 서 있는 마커**를 대상으로 하고, 마커 밖에 서 있으면 **바라보는 마커**를 대상으로 합니다.

### 마커

| 명령어 | 설명 |
|---|---|
| `/보트점프 막대기` | 마커 막대기를 받습니다. 블록을 좌클릭하면 첫째 지점, 우클릭하면 둘째 지점이 지정됩니다. 허공을 클릭하면 선택한 범위가 지워집니다. |
| `/보트점프 생성 <이름>` | 막대기로 선택한 범위로 마커를 만듭니다. |
| `/보트점프 삭제` | 지금 서 있거나 바라보는 마커를 지웁니다. |
| `/보트점프 삭제 <이름>` | 그 마커를 지웁니다. |
| `/보트점프 리스트` | 모든 마커의 이름과 그룹, 범위를 봅니다. |
| `/보트점프 정보` | 지금 서 있거나 바라보는 마커의 설정값을 봅니다. 그런 마커가 없으면 기본값을 봅니다. |
| `/보트점프 정보 <이름>` | 그 마커의 설정값을 봅니다. |
| `/보트점프 설정 <이름> <항목> <값>` | 그 마커의 설정값을 고칩니다. |

이름 자리에 `기본값`을 적으면, 마커 밖에서 쓰이는 기본값을 보거나 고칩니다. 새로 만드는 마커는 그때의 기본값을 물려받습니다.

### 그룹

그룹에 넣은 마커들은 그룹의 설정값을 함께 씁니다. 그룹에 속한 마커는 자신의 설정값 대신 그룹의 설정값을 따르므로, 그런 마커를 따로 고치려면 먼저 그룹에서 빼야 합니다.

| 명령어 | 설명 |
|---|---|
| `/보트점프 생성 그룹 <이름>` | 빈 그룹을 만듭니다. |
| `/보트점프 삭제 그룹 <이름>` | 그룹을 지웁니다. 속해 있던 마커는 그룹의 설정값을 물려받고 남습니다. |
| `/보트점프 정보 그룹 <이름>` | 그 그룹의 설정값과 속한 마커를 봅니다. |
| `/보트점프 그룹 추가 <그룹>` | 지금 서 있거나 바라보는 마커를 그 그룹에 넣습니다. 없는 그룹이면 새로 만듭니다. |
| `/보트점프 그룹 제거 <그룹>` | 지금 서 있거나 바라보는 마커를 그 그룹에서 뺍니다. 마커는 그룹의 설정값을 물려받습니다. |
| `/보트점프 그룹 리스트` | 모든 그룹과 속한 마커를 봅니다. |
| `/보트점프 그룹 정보` | 지금 서 있거나 바라보는 마커가 속한 그룹의 설정값을 봅니다. 뒤에 그룹 이름을 적어도 됩니다. |
| `/보트점프 그룹 설정 <그룹> <항목> <값>` | 그 그룹의 설정값을 고칩니다. 그룹의 모든 마커에 적용됩니다. |

### 점프블록

| 명령어 | 설명 |
|---|---|
| `/보트점프 점프블록 추가 <블록...>` | 보트가 뛰어넘을 블록을 추가합니다. 여러 개를 띄어 써서 한 번에 넣을 수 있습니다. |
| `/보트점프 점프블록 삭제 <블록...>` | 보트가 뛰어넘을 블록을 목록에서 삭제합니다. |
| `/보트점프 점프블록 리스트` | 보트가 뛰어넘는 블록의 목록을 봅니다. |

블록 이름은 `blue_ice`처럼 영어 식별자로 적습니다.

### 입력을 돕는 기능

- 명령어를 입력할 때 자동 완성 목록의 항목에 마우스를 올리면 설명이 보입니다.
- `/보트점프`만 입력하면 도움말이 나오며, 각 줄에 마우스를 올리면 설명이 보이고 클릭하면 입력창에 채워집니다.
- 영어로도 입력할 수 있습니다. (`/boatjump set <이름> speed 20`, `wand`, `create`, `remove`, `list`, `info`, `set`, `group add|remove|list|info|set`, `jumpblock add|remove|list`)

### 막대기를 들고 있을 때

- 범위가 선으로 표시됩니다. 이 선은 막대기를 든 플레이어에게만 보입니다.
- 마커 위에 서 있거나 마커를 바라보면, 그 마커의 이름과 그룹이 액션바에 표시됩니다.

| 선의 색 | 뜻 |
|---|---|
| 흰색 | 막대기로 선택 중인 범위 |
| 초록색 | 설정값을 고치지 않은 마커 |
| 파란색 | 설정값을 고친 마커 |
| 그 밖의 색 | 그룹에 속한 마커. 그룹마다 색이 다릅니다. |

## 설정 항목

| 한국어 | 영어 | 설명 | 초기값 | 범위 |
|---|---|---|---|---|
| `사용` | `enabled` | 마커의 속도 변화를 켤지 여부. `켜기` 또는 `끄기` | 켜기 | |
| `간격` | `interval` | 마커 안에서 속도 변화를 다시 적용하는 간격 (틱). `0`이면 들어설 때 한 번만 적용합니다. | `0` | 0~1200 |
| `속도` | `speed` | 마커에 들어설 때 보트의 속도에 더하는 값 (블록/초). 음수이면 느려집니다. | `0` | -100~100 |
| `계단` | `step` | 보트가 한 번에 오를 수 있는 높이 (칸). `0`이면 오르지 않습니다. | `1` | 0~100 |
| `탄성` | `elasticity` | 탄성 계수. 바닥에 떨어졌을 때에는 떨어진 속도에, 넘을 수 없는 벽에 부딪혔을 때에는 부딪힌 속도에 곱해서 되튑니다. `0`이면 튀지 않습니다. | `0` | 0~100 |
| `점프` | `bounce` | 바닥에 닿으면 이 속도(블록/틱)로 위로 띄웁니다. | `0` | 0~100 |

`속도`와 `사용`, `간격`은 마커 안에서만 쓰이고, `계단`, `탄성`, `점프`는 마커 밖에서도 기본값으로 동작합니다.

### 속도

초당 블록 수로 적습니다. 화면에 표시되는 m/s와 같은 단위입니다. `20`이면 초당 20블록 빨라지고, `-20`이면 그만큼 느려집니다. 느려지는 경우에는 멈추는 데까지만 줄어들고, 뒤로 가지는 않습니다.

`간격`이 `0`이면 마커에 들어설 때 한 번만 더하고, 간격을 정하면 마커 안에 있는 동안 그 틱마다 다시 더합니다.

### 계단

`1`이면 한 칸, `2` 이상이면 그 높이까지의 턱을 한 번에 오릅니다. 두 칸 이상의 턱은 아래부터 위까지 뛰어넘을 블록으로만 쌓여 있어야 오르며, 다른 블록이 섞여 있으면 벽으로 취급합니다.

### 탄성과 점프의 차이

| | `탄성` | `점프` |
|---|---|---|
| 세기의 기준 | 부딪힌 속도에 곱하는 비율 | 위로 띄우는 정해진 속도 |
| 작동하는 때 | 높은 곳에서 떨어져 바닥에 닿았을 때, 넘을 수 없는 벽에 부딪혔을 때 | 바닥에 닿아 있을 때 |
| 평지를 달릴 때 | 아무 일도 일어나지 않습니다. | 계속 튀어 오릅니다. |
| 방향 | 바닥에서는 위로, 벽에서는 뒤로 | 항상 위로 |

- 벽 자체를 마커로 지정해 두면, 그 벽에 부딪힌 보트에는 벽 마커의 `탄성`이 적용됩니다. 벽이 마커가 아니면 보트가 있는 자리의 설정값이 적용됩니다.
- 물 위에서는 벽에 부딪혀도 튕기지 않습니다. 보트를 물가에 댈 수 있게 하기 위해서입니다.
- `점프`는 마커 안에서는 블록의 종류와 관계없이 동작하고, 마커 밖에서는 슬라임 블록 위에서만 동작합니다. 값이 `0`이면 마커 안의 바닥은 튀지 않고, 슬라임 블록은 기본 세기(0.5)로 튑니다.

### 무작위 값

`속도`, `계단`, `탄성`, `점프`의 값 자리에 `무작위`(`random`)를 넣으면, 정해진 틱마다 값이 무작위로 바뀝니다.

```
무작위 [최소 최대] [틱]
```

| 입력 | 동작 |
|---|---|
| `무작위` | 항목별 기본 범위에서 4틱마다 바뀝니다. |
| `무작위 10` | 기본 범위에서 10틱마다 바뀝니다. |
| `무작위 0.5 3` | 0.5~3 사이에서 4틱마다 바뀝니다. |
| `무작위 0.5 3 20` | 0.5~3 사이에서 20틱마다 바뀝니다. |

### 속도의 한계

보트가 한 틱에 약 10블록(초당 약 200블록)보다 빠르게 움직이면, 서버가 "너무 빠르게 움직였다"고 판단하여 보트를 되돌려 놓습니다. 그래서 `속도`를 더한 결과와 벽에서 튕기는 속도는 이 한계를 넘지 않게 하고, `점프`에 9.5를 넘는 값을 넣으면 주의 문구가 나옵니다. 이 한계는 서버의 `spigot.yml`에 있는 `moved-too-quickly-multiplier` 값으로 정해집니다.

## 저장

마커와 그룹, 기본값, 뛰어넘을 블록 목록은 `plugins/BoatJump/markers.yml`에 저장되며, 서버를 재시작해도 유지됩니다.

## 알아 둘 점

- 보트의 움직임은 플레이어의 클라이언트가 계산하고, 서버는 그 위치를 조금 늦게 알게 됩니다. 그래서 핑이 높은 플레이어에게는 턱을 오르거나 벽에서 튕기는 시점이 조금 어긋날 수 있습니다.
- `/kill @e`처럼 모든 엔티티를 지우는 명령어를 쓰면 범위를 표시하는 선도 함께 지워집니다. 막대기를 다른 칸으로 바꾸었다가 다시 들면 선이 다시 그려집니다.

## 빌드

속도 패킷을 직접 보내기 위해 Paper 서버의 내부 jar를 참조합니다. 이 파일은 저장소에 포함되어 있지 않으므로, 먼저 Paper 26.3 서버를 `server` 폴더에서 한 번 실행하여 `server/versions/26.3/paper-26.3.jar`가 생성되도록 해야 합니다.

```
./gradlew build
```

빌드에는 JDK 25 이상이 필요합니다. 결과물은 `build/libs`에 생성됩니다.
